# 🎲 今日のサボり言い訳ジェネレーター

**行きたくないあなたの代わりに、乱数が全力で言い訳を考えるWebアプリです。**

ソフトウェア工学 期末課題7「AI駆動開発によるWebアプリ作成」の成果物として、
生成AI（Claude Code）を用いて開発しました。

## 📖 システムの概要

サボりたい状況（授業・バイト・飲み会など）と「本気度」を入力すると、
それに合わせた言い訳を自動生成し、**バレ確率**と一緒に表示するWebアプリです。
生成した言い訳は履歴として保存され、あとから見返すことができます。

### 入力・処理・出力

| 段階 | 内容 |
| ------ | ------ |
| **入力** | サボりたい状況（6種類から選択）＋ 本気度（1〜5のスライダー） |
| **処理** | 「前置き・理由・締め」の3パーツを本気度に応じた確率で合成し、理由ごとの「ヤバさ」からバレ確率を算出。結果をSQLiteに保存 |
| **出力** | 言い訳の文章、バレ確率（バー表示＋一言コメント）、過去の言い訳履歴 |

### 主な機能

- 🎲 **言い訳生成** — 状況×本気度に応じて数百通りの組み合わせから言い訳を合成
- 📊 **バレ確率の判定** — 言い訳の無理筋度をパーセント表示し、色付きバーと辛口コメントで評価
- 📜 **履歴の保存** — 生成した言い訳をSQLiteに保存し、直近10件を一覧表示
- 🧹 **証拠隠滅ボタン** — 履歴をワンクリックで全削除

## 🚀 実行方法（Dockerコンテナの起動）

Docker（Docker Desktopなど）がインストールされていることが前提です。

```bash
# 1. リポジトリをクローン
git clone https://github.com/pyonchan223/softeng_webapp.git
cd softeng_webapp

# 2. コンテナをビルドして起動
docker compose up --build
```

起動後、ブラウザで **<http://localhost:5000>** にアクセスしてください。

- 停止する場合は `Ctrl+C`、または `docker compose down`
- 言い訳の履歴はDockerボリュームに保存されるため、コンテナを再起動しても残ります
- 履歴も含めて完全に削除する場合は `docker compose down -v`

## 🖥 使い方

1. **「何をサボりたい？」** から状況を選ぶ（授業／バイト／飲み会／サークル／ゼミ・会議／デート）
2. **本気度スライダー** を調整する
   - `1` に近いほどネタに走った言い訳（例：「ハムスターが哲学的な問いを投げかけてきた」）
   - `5` に近いほど実際に使えそうな言い訳（例：「朝から熱っぽくて休みたい」）
3. **「言い訳を生成する」** ボタンを押す
4. 生成された言い訳と **バレ確率** を確認する
   - 40%未満（緑）: 通用する可能性が高い
   - 40〜70%（黄）: 五分五分
   - 70%以上（赤）: ほぼバレる
5. 気に入らなければ何度でも生成し直せます。過去の言い訳は画面下部の履歴に残ります
